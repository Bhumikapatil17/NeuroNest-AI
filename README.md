# NeuroNest AI

NeuroNest AI is an AI-powered personalized learning platform designed for students to improve productivity, learning, and exam preparation.

## Features

- AI Doubt Solver
- Quiz Generator
- Smart Flashcards
- Notes Summarizer
- AI Smart Timetable Generator

## Tech Stack

- React
- Vite
- Tailwind CSS
- Gemini API

## Key Highlights

- Premium modern UI/UX
- AI-powered educational assistance
- Personalized study timetable generation
- Interactive AI chat interface
- Responsive and elegant design

## Future Improvements

- Voice AI assistant
- PDF upload support
- Student progress tracking
- AI learning analytics

## Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/Bhumikapatil17/NeuroNest-AI.git
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Add Gemini API Key

Create a `.env` file and add:

```env
VITE_GEMINI_API_KEY=your_api_key
```

### 4. Run Project

```bash
npm run dev
```
